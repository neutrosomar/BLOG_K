## Archivos

- `index.php` - para verlo en tu PC
- `api/index.php` - entrada para Vercel
- `vercel.json` - configuración de Vercel (sin warning de builds)
- `assets/perfil.jpg` - foto
- `assets/styles.css` - estilos

## Ver en tu PC

```bash
php -S localhost:8000
```

Abre: http://localhost:8000

## Subir a Vercel

1. Sube la carpeta a GitHub
2. En Vercel: Import Project
3. Deploy
4. Redeploy si ya tenías un deploy anterior
